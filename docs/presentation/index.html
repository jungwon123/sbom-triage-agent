프로토타입으로 끝나지 않게 운영을 전제로 만들었습니다. 세 가지만 말씀드리겠습니다. 첫째, 한 번 분석하고 끝나지 않습니다. 서비스를 등록해 두면 주기마다 다시 스캔합니다. 코드가 그대로여도 새 취약점이 공개되거나 KEV에 오르면 분류가 바뀌고 알림이 갑니다. 둘째, 소스코드를 밖으로 내보내지 않을 수 있습니다. 2단계 모드에서는 사내 모델만 코드를 읽고 외부 모델은 사실만 받습니다. 실제로 돌려서 외부로 나간 요청 6건에 코드와 파일 이름이 없는 것을 확인했습니다. 다만 작은 사내 모델의 판독 정확도는 낮았고 이 부분은 더 큰 모델로 다시 재야 합니다. 셋째, 같은 코드가 노트북 한 대에서도, 쿠버네티스에서도 돕니다.

  • 샌드박스 검증은 npm 방식 저장소만 됩니다 (yarn, pnpm은 분류까지)
  • 정답 자료의 표본이 작습니다
  • 사내 모델의 판독 정확도를 재지 않았습니다
  • 쿠버네티스는 시험 클러스터에서만 확인했습니다

그래도 남는 것

  • 목록이 아니라 순서와 근거를 줍니다
  • AI가 틀려도 한 단계 안에서만 틀립니다
  • 조치안은 실행해 본 것만 내놓습니다
  • 마지막 결정은 사람이 합니다
